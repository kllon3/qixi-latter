# 七夕特辑 · 给乖乖的一封信

一封手机端优化的七夕情书网页。单文件、零依赖、无外链（微信内打开秒加载，国内访问无压力）。

## 功能

- 封面：月亮 / 双灯笼 / 银河 / 流星 / 星星闪烁 / 喜鹊飞过 / 漂浮爱心，点「打开信封」进入
- 倒计时入口：北京时间 2026-08-19 20:00 自动开放；提前开启密码为 `aifeifei`，第二段提示在 18:00 后显示
- 到达七夕封面后，点击「打开信封」直接阅读信稿，不再设置第二段口令
- 信纸：秦观《鹊桥仙》为引，四句词分节，正文分段重排，滚动渐显，点击页面任意处有爱心飘出
- 无背景音乐（纯静音页面，避免打扰阅读）
- 已加 `<meta name="robots" content="noindex">`，搜索引擎不会收录
- 适配微信内置浏览器与手机屏幕

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 部署到 GitHub Pages（免费，约 5 分钟）

1. 在 GitHub 新建一个仓库，名字取**难猜一点**的（例如 `qixi-2026-secret`），选择 **Public**（Pages 免费版只支持公开仓库）。
2. 用 VS Code 打开本文件夹，按你之前学的 git 流程：
   - 终端执行 `git init` → `git add .` → `git commit -m "qixi letter"`
   - 关联远程：`git remote add origin https://github.com/你的用户名/仓库名.git`
   - `git push -u origin main`
3. 仓库页面 → **Settings** → 左侧 **Pages**：
   - Source 选 `Deploy from a branch`，Branch 选 `main`，目录 `/ (root)` → Save
4. 等 1~3 分钟，页面顶部会给出地址：`https://你的用户名.github.io/仓库名/`
5. **务必先在手机微信里打开这个地址测试一遍**（测试倒计时密码、打开信封、查看信纸效果），确认无误再发给她。
